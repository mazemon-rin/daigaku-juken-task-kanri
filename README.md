# Study Tracker

大学受験の勉強時間、今日やること、1日の計画をブラウザだけで管理するWebアプリです。

HTML、CSS、JavaScriptだけで作っているため、GitHub Pagesでそのまま公開できます。データは使っているブラウザのLocalStorageに保存されます。

## 主な機能

- 勉強タイマーと休憩タイマー
- タイマー終了時の通知音
- バイブレーション対応ブラウザでの振動通知
- タイマー中の画面スリープ防止
- 今日の勉強記録
- 今日やることリスト
- 1日の計画
- 履歴、分析、月間カレンダー
- 目標時間と試験日カウントダウン
- CSV保存、CSV読込
- JSONバックアップ、JSON復元
- ダークモード

## 使い方

1. 科目を入力します。
2. 勉強時間と休憩時間を設定します。
3. 「スタート」を押して勉強を始めます。
4. 終わったら「今すぐ記録」、またはタイマー終了時に記録します。
5. 「今日やること」や「1日の計画」は目標画面から入力できます。

## データ保存について

このアプリのデータは、ブラウザ内のLocalStorageに保存されます。

同じ端末・同じブラウザでは続きから使えますが、ブラウザのデータを削除すると記録も消える場合があります。大切な記録は、ホーム画面の「データを保存」または設定画面の「JSONバックアップ」から保存してください。

## 公開方法

GitHub Pagesで公開する場合は、このリポジトリをGitHubにアップロードし、Pagesの公開元を `main` ブランチに設定します。
